# Changes-in-life-0.0.1
«Перемены» — школьная история об осени, выборе и взрослении.  Сентябрь. Новый класс, новые лица, первое настоящее чувство и первая серьёзная ошибка. Здесь не нужно быть идеальным — достаточно быть честным.  Игра находится в стадии пре-альфы: Все еможет поменяться.  Музыка и звуки — CC0 (авторы указаны на экране «Авторы и лицензии»).
